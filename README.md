# Ludoteca Maldita - Re-Animator

Aplicación fanmade para **Arkham Horror: The Card Game** desarrollada por el equipo de **Ludoteca Maldita** para el evento realizado el dia 30 de Ocutbre de 2026 en la tienda

## Uso

La aplicación está contenida en un único archivo `index.html`, por lo que no necesita instalación ni servidor especial.

## Aviso

Contenido fanmade. Prohibida su venta. Ludoteca Maldita, Arkham Horror: The Card Game y sus marcas pertenecen a sus respectivos propietarios.
